校園 FAQ AI 智慧語意搜尋系統

Python × Ollama × Embedding

01｜專題介紹

本專題透過 AI 語意搜尋技術， 協助大學生快速查找校園常見問題。

即使使用者的提問與 FAQ 資料庫的文字不同， 系統仍能比較語意相似度，找出相關資訊。

02｜主要功能

  • 使用自然語言查詢校園問題
  • Embedding 語意向量搜尋
  • 支援多種常見問法
  • 顯示前三筆相關 FAQ
  • 相似度門檻與拒答機制
  • 提供 FAQ 答案及資料來源

03｜如何執行

先安裝 Python、uv 和 Ollama。

ollama pull qwen3-embedding:0.6b
uv sync
uv run python main.py

執行後，在終端機輸入校園相關問題。

輸入 exit 可以結束程式。

05｜AI 使用說明

AI 模型： qwen3-embedding:0.6b

使用位置： FAQ 與使用者問題的語意向量轉換。

Python 負責： 資料讀取、相似度計算、排序與結果顯示。

ChatGPT 輔助： 系統規劃、程式撰寫、錯誤排除及測試設計。

開發者自行執行模型、測試不同問法， 並調整資料與搜尋邏輯。
